# Second-Brain-repo

A full-stack Second Brain web application to save, organize, and share your links, tweets, YouTube videos, and bookmarks.

## Tech Stack
- **Backend:** Node.js, Express, TypeScript, MongoDB, Mongoose, JWT
- **Frontend:** React, Vite, TypeScript, Tailwind CSS

## Project Structure
- `second-brain-backend/`: Express REST API and database models
- `second-brain-frontend/`: React frontend user interface
